TRACK A · HANDS-ON EXERCISE

Scope the readmission integration

One real request, four deliverables, about four hours — no code

Mohcine Madkour, PhD · HL7 FHIR Integration for Clinical AI

Welcome to the Track A hands-on exercise. You’ve learned three things in Module 1: how to decide whether to build, how to pick a pattern, and how to write the Interface Design Document. Now you’ll use all three on one realistic request, from start to finish. There’s no code in this exercise. But it’s still hands-on: you’ll produce four real documents, and at the end you’ll open a real HL7 v2 feed and find the problems in it. Budget about four hours. You don’t have to do it in one sitting. Everything you need is in the resources for this lecture.
