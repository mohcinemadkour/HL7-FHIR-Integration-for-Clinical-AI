Step four is where this exercise gets hands-on. In the resources you’ll find a file with five HL7 v2 discharge messages — ADT A03 — from Lakeside’s test system. The patients are fictional. On screen is the first message, and it’s a clean one. I’ve highlighted the four fields to check. MSH-10, the message control ID — it should be unique for every message. PID-3, the patient’s MRN. PV1-36, the discharge disposition — 01 means discharged home. And PV1-45, the discharge date and time. You don’t need to know HL7 v2 in depth yet; that’s Track B. To find a field, count the pipe characters. One tip: in the MSH segment, the first pipe is itself field one. Now open the file and check the other four messages. Every problem you find is a real decision for your IDD: what happens to that message, who gets alerted, and which assumption you now have to test. Find at least three.
