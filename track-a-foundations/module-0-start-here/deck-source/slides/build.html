WHAT YOU’LL BUILD

Three working pipelines

01

HL7 → FHIR integration channel

Mirth ingests ADT and ORU feeds and posts FHIR Patient and Observation resources to HAPI FHIR

02

Real-time sepsis risk pipeline

FHIR features into an XGBoost model, CDS Hooks alert cards, results saved as RiskAssessment

03

Clinical NLP pipeline

Notes from DocumentReference, scispaCy extraction, structured Observations written back

By the end of the course, you’ll have built three pipelines. Number one: an HL7-to-FHIR integration channel. A Mirth Connect channel that takes live HL7 v2 ADT and ORU messages, parses the clinical observations, and posts them as FHIR R4 Patient and Observation resources to a local HAPI FHIR server. Number two: a real-time sepsis risk pipeline. You’ll extract features from FHIR, run them through an XGBoost model, surface the result as a CDS Hooks alert card in the clinician’s workflow, and store the score as a FHIR RiskAssessment. Number three: a clinical NLP pipeline. You’ll pull notes through FHIR DocumentReference, extract medications and diagnoses with scispaCy, and write structured Observations back. These are portfolio pieces. Put them on GitHub, show them in interviews, or use them as the starting point for real work.
