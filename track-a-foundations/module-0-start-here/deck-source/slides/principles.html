HOW I TEACH

Three rules for this course

Pipelines over slides

Every module ends with something that runs.

Code over definitions

You learn HL7 by parsing it, not memorizing it.

Judgment over lookup

I’ll show you the trade-offs, not just the spec.

So here are the three rules I followed when I built this course. First: pipelines over slides. I’ll use slides to frame ideas, but every module ends with something that actually runs on your machine. Second: code over definitions. You won’t memorize the HL7 segment list. You’ll parse real messages, and the segments will stick because you needed them. Third: judgment over lookup. Anything you can look up, I’ll keep short. Where I’ll slow down is on the decisions: HL7 v2 or FHIR for this use case, where to put the transformation logic, when to say no to an interface request. That’s where experience matters, and that’s what I want to pass on to you.
