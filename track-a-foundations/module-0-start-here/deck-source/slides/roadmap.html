Here’s the map of the whole course: four tracks, ten modules. Track A is foundations and scoping. You’re in Module 0 right now — this orientation. Module 1 comes before any code, on purpose. We’ll ask the questions that should come first on any integration project: should you build this interface at all? Is HL7 v2, FHIR or an API the right pattern? And you’ll write your first Interface Design Document. Track B gives you the fundamentals, Modules 2 to 4: HL7 v2 messaging, FHIR R4, and Mirth Connect channel engineering. This is where you build your first pipeline, from HL7 v2 to FHIR. Track C, Modules 5 to 7, takes you into production integration: SMART on FHIR and CDS Hooks with Epic, building features from FHIR resources, and running real-time inference. That’s where the sepsis pipeline comes together. And Track D, Modules 8 and 9, covers clinical NLP, compliance and MLOps — de-identification, the model registry, drift monitoring and FDA software-as-a-medical-device considerations. You can go straight through. If you already know HL7 v2 well, feel free to move faster through Track B — but don’t skip Track A.
