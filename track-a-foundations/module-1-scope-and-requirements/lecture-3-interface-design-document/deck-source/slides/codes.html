• Moving data is easy. Making it mean the same thing is hard. • Hospitals send local codes: LACT, LACTIC, or a number. • A model trained on one site's codes gets nothing at another site. • Map every concept to a standard code. • LOINC for labs and vitals. SNOMED CT for problems. RxNorm for meds. • ICD-10 for billing diagnoses. UCUM for units. • Wrong mapping = wrong model, with no error message. • The mapping table goes in the IDD.
