• Define “done” before you scope anything. • Layer 1: it works. Delivery, completeness, latency, uptime. • Layer 2: people use it. Cards seen, acted on, override rate. • Layer 3: it changes the outcome. For sepsis: time to escalation. • Each layer stands on the one below. • Put at least one metric per layer in the IDD. • Only layer 1? You can prove it works — not that it was worth building.
