• Section 5: what happens when it fails. It will. • Validation error: the message is wrong. Reject to an error queue; review daily. • Business-rule error: valid, but breaks a rule — unknown MRN. Hold, retry, review. • System error: the other side is down. Retry with backoff; page if it persists. • For each: what happens, who's alerted, how it's resolved. • Log everything, success and failure. • The AI-specific failure: the feed stops quietly, the model scores stale data. • Alert on data freshness, not just errors.
